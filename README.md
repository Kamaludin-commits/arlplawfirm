# ALP Law Firm — Multi-Page Website

Official static site for https://arlplawfirm.web.id/ — GitHub Pages.

## Upload / replace safely
1. Extract this ZIP to a local folder. Do not upload the ZIP itself.
2. In the existing GitHub repository `Kamaludin-commits/arlplawfirm`, open **Add file → Upload files**.
3. Drag **all files and the `assets` folder** from inside the extracted folder.
4. GitHub will identify replacements (`index.html`, `styles.css`, `script.js`) and additions (`services.html`, `people.html`, etc.). Commit changes to `main`.
5. Keep the existing `CNAME` in the repository. Do NOT remove it or change GitHub Pages settings.
6. `about.html` should be REPLACED by the supplied complete version.
7. If uploading from the browser, make sure `index.html` is at the top level of the repository, not within a nested folder.
