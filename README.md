# ALP Law Firm — Jakarta Skyline Editorial Website

This version follows the editorial visual direction in the supplied HHP reference screenshot while using ALP's own firm identity and information from the provided 13-page Company Profile. It is **not** an HHP website or reproduction of their logo, writing or photo.

## Free GitHub Pages publication
1. Extract `arlplawfirm-reference-style.zip` on your computer.
2. Create or open the public GitHub repository `arlplawfirm`.
3. Upload `index.html`, `styles.css`, `script.js`, `favicon.svg`, and the complete `assets/` folder **to the repository root**. Upload the extracted files, not the ZIP.
4. Commit changes. In Settings → Pages choose Deploy from a branch → `main` → `/(root)` → Save.
5. Expected site URL: https://kamaludin-commits.github.io/arlplawfirm/
